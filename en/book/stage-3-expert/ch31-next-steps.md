# Ch 31 · Next Steps on Three Paths

> **Stage**: 尾章 · Closing | **Pillar**: 工程师修炼

## Core Question

Where do you go from here?

---

## Path 1: Traditional Software Engineering (SE Track)

**Covered by this book**: Computational thinking, systems understanding, engineering practice.

**Next depth targets**:
- **Storage systems**: database internals (CMU 15-445), distributed storage (Dynamo, Bigtable papers)
- **Networking**: TCP/IP deep dive, *Computer Networks* (Tanenbaum)
- **Compilers**: understand your runtime — *Crafting Interpreters* (Nystrom)
- **Open source contribution**: find a project where you read the code faster than the docs

**The L2 signal**: Others bring you ambiguous problems. You help them define the problem before solving it.

---

## Path 2: AI Engineer Track

**Covered by this book**: Full 5 pillars including math, ML, deep learning, LLMs.

**Next depth targets**:
- **Research paper reading**: start with foundational papers (Attention Is All You Need, BERT, InstructGPT)
- **AI evaluation and safety**: HELM benchmark, red-teaming methodology
- **Large-scale ML engineering**: *Designing Machine Learning Systems* (Huyen)
- **Applied AI**: build and ship an AI product end-to-end, including evaluation infrastructure

**The L2 signal**: You can scope AI projects — decide what's worth building and what's not.

---

## Path 3: CS Research Track

**Covered by this book**: Computational thinking, mathematics, theory foundations.

**Next depth targets**:
- **How to read papers**: Keshav's three-pass method
- **Choosing a research direction**: follow the problems, not the hype
- **The PhD path**: research proposal, advisor fit, conference vs journal culture
- **Staying grounded**: connect theory to engineering — the best theorists solve real problems

**The L2 signal**: You identify open problems. Others didn't notice the question you're asking.
