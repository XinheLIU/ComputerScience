# Ch 1 · From Problem to Algorithm

> **Stage**: 第一阶 · Foundations (L5 → L4) | **Pillar**: Computational Thinking

## Core Question

What is computation? Why can programs solve problems?

## Soul Insight

An algorithm is not code — it is a formalized thought process. Reduction, induction, and recursion are three meta-tools that underlie almost every algorithm ever written. Learning to see problems in terms of these three tools is the first step toward computational thinking.

## Concepts

- What is an algorithm: determinism, finiteness, correctness
- Complexity intuition: how to reason about "how fast"
- Recursion mental model: trust the base case + trust the recursive leap
- The three meta-tools: reduction (transform to a known problem), induction (prove it works), recursion (solve smaller instances)

## Practice Anchor

Analyze three classic problems using the three meta-tools:

| Problem | Tool | Key Insight |
|---------|------|-------------|
| Fibonacci | Recursion → Dynamic Programming | Overlapping subproblems |
| Binary Search | Reduction + Induction | Halving the search space |
| Tower of Hanoi | Recursion | Trust: move n-1 discs, then one |
