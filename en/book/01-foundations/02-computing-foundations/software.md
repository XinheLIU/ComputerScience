## Server

1. **Apache (HTTP server)**
   - **Summary:** A widely-used open-source web server software that serves web content over HTTP and HTTPS protocols. It is known for its flexibility, robust features, and extensive module ecosystem.

2. **Nginx (HTTP server)**
   - **Summary:** A high-performance web server and reverse proxy server, popular for its speed, scalability, and efficient handling of concurrent connections. Often used for serving static content and as a load balancer.
       - ![[Screenshot 2025-07-16 at 18.33.08.png]]
