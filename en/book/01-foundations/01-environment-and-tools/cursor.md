## Installation and set-up

> <https://www.cursor.com/features>

- Cursor is a code editor that serves as a fork of Visual Studio Code (VS Code), designed to enhance coding productivity by integrating artificial intelligence (AI) capabilities directly into the development environment. This relationship allows Cursor to maintain a familiar interface for users transitioning from VS Code while also offering unique features tailored for AI-assisted coding
  - Main Features
    - AI code completion
    - Chat panel
    - Code search
    - Function explanations
    - Refactoring help
  - Key Benefits
    - Faster coding
    - Less googling needed
    - Smart suggestions
    - Works like a coding partner
- Set Up
  - Keybinds
    - Cmd + I : composer, Cmd + L: chat; Cmd + Shift + P: command pallettes
  - Settings
- Git set-up

### Codebase

 1. @Codebase function
     1. Contextual Search: When you use `@Codebase`, Cursor performs a detailed search across your entire codebase, scanning for relevant files and code snippets that pertain to your query. This allows for a more comprehensive understanding of the context surrounding your code.
     2. Process Steps:
         1. Gathering: It scans through your codebase to identify important files and code chunks.
         2. Reranking: The gathered context items are then reordered based on their relevance to your specific query.
         3. Reasoning: Cursor analyzes the context to formulate a plan for using the relevant code.
         4. Generating: Finally, it generates a response or suggestion based on the analyzed context
     3. Usage in Queries: By typing `@Codebase` in your query, you can ask questions about your entire project, allowing Cursor to provide detailed information and relevant code snippets, which is particularly useful for understanding complex codebases or tracing execution flows
     4. Integration with Other Features: You can combine `@Codebase` with other commands, such as pressing `Ctrl/⌘ + Enter`, to enhance the accuracy and depth of the responses generated by Cursor Chat
 2. Index
     1. Settings: default open
     2. .cursorignore file
 3. **Analyze and answer questions about the project**
 4. **Search function or file locations**
 5. **Improve base on current code**

### Code Version Control

1. Use Git
2. Save all vs accept all
  1. "save all" are useful when "after generating multiple files, you partially reject and accept them based on verification results"
3. **Create a History log file** then add it into the context
  1. Eg add following in cursorrules

```Plain
After each conversation request ends, conduct a conversation summary. Whether generating new files or modifying existing ones, a summary is required. Append the summary content to the Readme file (indicating that the content in the file accumulates incrementally). The summary content should include:
- The main purpose of the conversation
- The main tasks completed
- Key decisions and solutions
- The technology stack used
- Which files were mod`ified
```

### Agent mode （YOLO Mode）

1. Agent mode
    - Can complete tasks by itself **using the command line.**
    - Can **determine which files are needed as context by itself.**
    - Know what should do in next step.
2. Normal mode
    - Cannot use the command line.
    - Requires the user to specify the context.
    - Wait for your command for next step.
3. Agent Setting
    - YOLO mode: allow cursor to run commands without confirmation
    - YOLO prompts/black/whitelist : prevent file deletions, git deletions, etc
