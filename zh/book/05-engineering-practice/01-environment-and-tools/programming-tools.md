## Reference
- **版本控制与代码托管**：
    - Git 是软件开发工作流基础，能创建代码快照，形成项目历史，支持团队成员在不同分支协作，其分布式特性让每个开发者有完整项目副本，可离线工作
    - GitHub 基于 Git 创建代码社交网络，拉取请求功能方便团队审查代码，还提供问题跟踪等功能。GitLab 则是完整的 DevOps 平台，集成代码托管与 CI/CD 流水线，可自托管，具备安全扫描等功能。
    - GitHub Actions 能将 GitHub 转换为 CICD 引擎，借助 YAML 定义工作流程，配合社区预构建操作实现自动化。
- **容器化与编排**
    - Docker 将应用程序及其依赖打包成轻量级、便携且环境一致的容器，通过编写 Dockerfile 构建镜像，可在不同环境运行
    - Kubernetes 用于大规模运行容器，它将容器分组为 Pod，自动处理部署、缩放与恢复，保障应用平稳运行。
- **自动化与配置管理**：
    - Jenkins 是老牌自动化服务器，凭借超 1500 个插件实现与多种工具集成，通过 Jenkins 文件定义管道，可在多代理间分配工作负载，具有高可扩展性。
    - Ansible 采用无代理方式简化服务器配置，通过编写 YML playbook 描述系统期望状态，幂等性确保重复运行不会出错，支持批量操作。
    - Terraform 将基础设施视为代码，通过编写配置文件并结合 API 调用构建跨多个云服务提供商的基础设施，可对基础设施进行版本控制，实现可重复、一致的协作。
- **监控、日志与质量分析**：
    - Grafana 连接数据源构建交互式可视化仪表板，实时呈现系统指标。
    - Sonar Cube 持续分析代码库，查找错误、漏洞和代码异味，集成到 CI/CD 管道可阻止问题代码进入生产。
    - HashiCorp 提供 Vault（管理敏感信息）、Consul（连接混合云服务）、Packer（构建多平台机器映像）等工具。
    - ELK Stack（Elasticsearch、Logstash、Kibana）集中管理日志，实现快速搜索与可视化。
    - CircleCI 提供云端的 CI/CD 简化方案，通过配置文件定义管道，借助预建集成和智能缓存加速构建。
    - Prometheus 是云原生应用监控标准，主动抓取指标，结合 Alertmanager 通知异常，与 Grafana 配合提供完整监控方案。
