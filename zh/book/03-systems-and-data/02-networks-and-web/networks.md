## 通信

现代通信系统是**硬件、软件与传输技术**的高度结合。虽然技术不断进步，但核心矛盾依然集中在**有限资源（频谱/带宽）的分配、隐私保护与安全加固**等方面。
无线技术虽日益普及，但其广播特性使其极度依赖加密技术（如WPA）

### 通信：从历史到现代的演进

* **早期通信手段**：
  * **人力/马匹**：如马拉松信使费迪皮迪兹、波斯帝国的骑手体系，以及美国西部的驿马快信（Pony Express）。
  * **光学电报**：18世纪末发明的机械臂/百叶窗系统（查佩电报）。它是**真正的数字通信系统**，因为信号仅出现在固定位置。
  * **核心挑战**：历史上已显现标准建立、错误检测、安全与隐私（如“中间人攻击”）等问题。
* **电子通信的革命**：
  * **电报**：莫尔斯在19世纪40年代推广，取代了受天气限制的光学电报。
  * **电话**：亚历山大·格雷厄姆·贝尔（1876）发明。传统电话系统以**高可靠性**和**保障服务质量**为核心，具有全球唯一的地理标识号码。
* **现代变迁与网络中立性**：
  * **VoIP（互联网电话）**：Skype、冯纳奇（Vonage）等服务利用互联网传输语音，极大地降低了成本。
  * **网络中立性（Net Neutrality）**：争论焦点在于互联网服务提供商（ISP）是否有权干扰、限制或屏蔽特定流量（如限制竞争对手的VoIP或流媒体速度）。

### 网络技术基础

* **网络性能度量**：
  * **带宽（Bandwidth）**：数据的传输速度（如 Mbps、Gbps）。
  * **延迟（Latency/Delay）**：信息块通过系统所需的时间。
  * **抖动（Jitter）**：延迟的可变性，对音视频实时通话至关重要。

* **家庭连接技术**：
  * **调制解调器（Modem）**：执行调制（比特转信号）与解调（信号转比特）的装置。
  * **有线电视（Cable）**：共享媒介，下行速度快但需加密保护隐私。
  * **DSL（数字用户线路）**：通过电话线发送数据，非共享媒介，但受距离交换局长度限制（约5公里）。
  * **光纤（Fiber）**：利用光脉冲传输，损耗低、速度极快，是目前最先进的有线连接方式。

#### 局域网与以太网（Ethernet）

* **起源**：20世纪70年代由施乐帕洛阿尔托研究中心（Xerox PARC）发明。
* **地址与识别**：
  * **以太网地址（MAC地址）**：每个设备拥有唯一的48位十六进制标识号。
  * **数据包（Packet）**：网络传输的基本单位，包含源地址、目的地址和约1500字节的数据载荷。
* **冲突与安全**：
  * **争用处理**：当两台设备同时发送产生冲突时，会各自随机等待一段时间后再重试。
  * **嗅探（Sniffing）**：在“混杂模式”下，软件可以读取网络上所有未经加密的消息。

#### 无线网络技术

* **Wi-Fi (IEEE 802.11)**：1999年发布
  * 使用无线电波传输数据，受距离、墙壁和干扰影响。
  * **频谱管理**：由政府机构（如美国FCC）分配，不同技术（Wi-Fi、微波炉、蓝牙）可能在相同频段（如2.4GHz）产生竞争。
* **蓝牙 (Bluetooth)**：低功耗、短距离（1-100米）通信，常用于键鼠、耳塞和遥控器。
* **RFID（射频识别）**：低功耗标签技术，用于门禁、宠物芯片、护照等。
* **GPS（全球定位系统）**：**单向无线系统**。卫星发送时间/位置信息，接收器计算坐标。**注意**：GPS本身无法跟踪用户，必须配合地面转发系统（如手机）才能实现追踪。

#### 移动电话（蜂窝系统）网络

* **蜂窝结构**：将地理区域划分为六边形“单元”，每个单元设基站。
* **频率复用**：不相邻的单元可以重复使用相同频率，提高了频谱利用率。
* **身份识别**：
  * **IMEI**：手机唯一的15位数字识别码。
* **移动管理**：手机开机后与最近基站保持联系，位置更新由后台系统同步，以确保来电时能找到手机。
* **安全性**：
  * **黄貂鱼（Stingray）**：一种模拟基站的设备，可用于拦截、监视附近的手机流量（中间人攻击）。
* **代际演进**：
  * **4G LTE**：侧重数据传输的演进。
  * **5G**：更高带宽（最高可达10Gbps）、更短延迟，并在短程连接中使用高频波段。

### 压缩与错误处理

#### 数据压缩（Compression）

* **原理**：去除冗余信息。
* **无损压缩**：
  * **霍夫曼编码**：利用不等长编码（高频元素短，低频元素长）。
  * **ZIP/bzip2**：查找并替换重复的短语序列。
  * **PNG**：适用于线条艺术和块状颜色。
* **有损压缩**：利用感知冗余，丢弃人类肉眼或耳朵察觉不到的信息。
  * **JPEG**：图像压缩。
  * **MP3/AAC**：音频感知编码，利用声音掩蔽效应。
  * **MPEG**：视频压缩，只对帧与帧之间变化的部分进行编码。

#### 错误检测与纠正

* **校验和（Checksum）**：如信用卡和ISBN号使用的**卢恩算法（Luhn Algorithm）**，通过特定的数学运算验证数字的合法性。
* **奇偶校验（Parity Bit）**：在二进制数据中添加额外的一位，使1的个数为奇数或偶数，用于检测单比特错误。
* **纠错码**：更复杂的算法（如CD/DVD使用的技术），不仅能发现错误，还能通过冗余信息修复损坏的位。

## 互联网

### 互联网概述与核心原理

诞生与定义

* **诞生时刻**：1969年10月29日，第一条ARPANET信息从UCLA发送到斯坦福大学。最初尝试发送“LOGIN”时系统崩溃，仅成功发送了“LO”。
* **本质属性**：互联网并非单体巨型计算机，而是**松散、非结构化、自组织的网络集合**。它通过统一的标准（协议）将物理属性截然不同的网络（如光纤、Wi-Fi、以太网）连接在一起。
* **设计初衷**：具备**健壮性**。即使局部网络出现故障，系统仍能通过其他路径实现数据路由。

核心运行机制

- 局域网与广域互联
  - 局域网用于家庭/办公室内部（以太网 / Wi-Fi）
  - 路由器/网关负责把一个局域网连接到外部网络（ISP）
- 数据以“包”为单位传输
  - 每个包含：源地址、目的地址、长度、有效负载
  - 大 IP 包会拆成多个物理包，比如以太网最大 1500 字节
- 数据可能跨越多个国家、多个机构
  - 一个 IP 包可能经过 20+ 个网关，属于 10+ 不同机构
  - 许多非美国家的数据仍经由美国电缆，NSA 利用这一点进行监听

为了实现全球规模的互联，互联网必须解决四个关键问题：

- 地址 (Addressing)：为每台主机提供唯一标识。
- 名称 (Naming)：提供人类易读的标识（域名）。
- 路由 (Routing)：在复杂网络中寻找传输路径。
- 协议 (Protocols)：定义通信的规则和格式。

互联网的成功逻辑

* **端到端原则**：网络本身是“哑”的，只负责复制字节；智能和复杂性留在网络边缘的“终端”（计算机程序）。这极大地促进了创新。
* **开放性与风险**：早期的设计基于相互信任的学术社区，缺乏原生安全机制。当下的互联网正处于一场持续的安全军备竞赛中。

### 标识系统：IP地址与域名

#### IP 地址 (Internet Protocol Address)

* **IPv4**：32位地址，通常以**点分十进制**表示（如 `140.180.223.42`）。由于地址资源（约43亿个）已枯竭，目前正向 IPv6 迁移。
* **IPv6**：128位地址，提供近乎无限的地址空间（约  个）。
* **NAT (网络地址转换)**：允许一个外部 IP 地址服务于多个内部设备，有效缓解了 IPv4 地址短缺问题。

#### 域名系统 (DNS)

* **功能**：充当互联网的“电话簿”，将人类可读的域名（如 `baidu.com`）转换为机器可识别的 IP 地址。
* **层级结构**：
  * **顶级域名**：`.com`、`.edu` 以及国家代码（如 `.cn`、`.tv`）。
  * **根服务器**：全球共有13台逻辑根服务器，负责引导所有域名查询。
* **缓存机制**：为了加速访问，本地名称服务器会缓存最近查询的结果。

### 传输架构：路由与 TCP/IP 协议

#### 路由 (Routing)

* **网关/路由器**：专门负责将信息包从一个网络转发到另一个网络的计算机。
* **动态特性**：网关通过交换路由信息不断刷新路径，路径选择不一定是物理最短路径，而是基于成本和便利性。
* **分层结构**：由数万个**自治系统 (AS)** 组成，通常对应大型ISP（Internet Service Provider)。

#### TCP/IP 协议栈 (四层模型)

互联网采用分层思维来控制复杂性，每一层只关注特定任务：

1. **应用层**：HTTP（网页）、SMTP（邮件）、SSH（远程登录）。
2. **传输层**：
   * **TCP**：可靠的双向流，负责纠错、排序、重传。
   * **UDP**：不可靠但高效，适用于视频流、游戏和 DNS。
3. **网络层 (IP)**：定义数据包格式，提供“尽力而为”的传输（无连接、不可靠）。
4. **链路层**：具体的物理硬件（以太网、Wi-Fi 等）。

常见高层应用协议

| 协议名称 | 全称 | 主要用途 | 端口 |
| --- | --- | --- | --- |
| **HTTP** | HyperText Transfer Protocol | 万维网网页传输 | 80 |
| **SMTP** | Simple Mail Transfer Protocol | 发送电子邮件 | 25 |
| **IMAP** | Internet Message Access Protocol | 远程访问和管理邮件 | 143 |
| **SSH** | Secure Shell | 加密远程登录（替代不安全的 Telnet） | 22 |
| **DNS** | Domain Name System | 名称与地址转换 | 53 |

### 互联网的演进与社会挑战

资源管理与权力

* **IETF (互联网工程任务组)**：通过发布 **RFC** 文档制定技术标准。
* **ICANN**：负责 IP 地址、域名分配等关键资源的协调。
* **主权与控制**：各国政府对互联网治理的参与度增加，导致了“防火墙”和网络巴尔干化（碎片化）的风险。

法律与版权

* **点对点 (P2P)**：如 Napster 和 BitTorrent，改变了内容分发模式，也引发了巨大的版权争议。
* **DMCA (数字千年版权法案)**：
  * **避风港原则**：ISP 在收到侵权通知并删除内容后可免责。
  * **副作用**：有时被用于反竞争目的（如限制第三方硬件适配）。

物联网 (IoT)

* **定义**：将日常设备（摄像头、灯泡、恒温器）接入互联网。
* **安全隐患**：由于制造商往往忽视安全，IoT 设备常成为黑客攻击的载体（如默认密码漏洞、隐私泄露、僵尸网络攻击）

## 万维网  (World Wide Web) 

### 万维网与互联网的区别

* **互联网 (Internet)**：基础设施、通信基板，类似于公路系统，负责让计算机交换信息。
* **万维网 (Web)**：运行在互联网之上的应用服务，类似于公路上的车流和快递业务，连接提供信息的服务器和请求信息的客户端。

万维网的社会影响

* **权利与治理**：匿名权与实名制的博弈、跨国司法管辖权冲突。
* **过滤泡沫**：算法推荐可能导致人们只看自己想看的信息，限制视野。
* **端到端信任**：Web 最初基于信任设计，而现在的趋势是转向全加密（HTTPS）和主动防御机制。

### 万维网的核心支柱 (Web 的四大要素)

1. **URL (统一资源定位符)**：信息资源的地址（如 `http://www.example.com`）。
   - **编码规则**：URL 不允许空格和非字母数字字符。空格用 `+` 表示，其他字符用 `%` + 十六进制代码（如单引号为 `%27`）
2. **HTTP (超文本传输协议)**：客户端与服务器通信的“语言”。
3. **HTML (超文本标记语言)**：描述网页内容和表现形式的标记语言。
4. **浏览器 (Browser)**：解析 URL、执行 HTTP 请求并渲染 HTML 的工具（如 Chrome、Edge、Firefox）。

### 网页技术：从静态到动态

#### HTML与CSS

* **HTML（HyperText Markup Language）**：使用标签（如 `<body>`, `<img>`, `<a>`）定义内容结构。
* **CSS (层叠样式表， Coding Style Sheets)**：独立于内容的语言，负责网页的样式（颜色、字体、布局）。
* **注意**：HTML和CSS不是编程语言，因为它们没有循环和逻辑判断功能。

#### 客户端脚本与插件

* **JavaScript**：
  * **定义**：浏览器内运行的代码，发送的是源代码，在本地编译
  * **用途**：实现图形特效、表单验证、弹出窗口和复杂的交互
* **Java**：早期用于扩展浏览器（Java Applet），但现已基本退出 Web 舞台
* **插件 (Plugins)**：由第三方编写的程序（如早期常用的 Flash、Adobe Reader），用于处理视频和 PDF。因安全漏洞频发，HTML5 正逐渐取代插件功能

#### 状态管理：Cookie

* **无状态性**：HTTP 协议本身不记住客户端信息。
* **Cookie**：服务器发送给浏览器存储的一小段文本（约 4KB）。浏览器再次访问同一服务器时会带上它，实现“记住登录状态”或“购物车”功能。
* **争议**：常被用于跟踪用户行为以进行定向广告投放。

### 网络安全：威胁与风险

#### 恶意代码分类

* **病毒 (Virus)**：需要**人工干预**（如点击附件）才能传播。
* **蠕虫 (Worm)**：利用系统漏洞**自动传播**（如 1988 年莫里斯蠕虫）。
* **特洛伊木马 (Trojan)**：伪装成合法软件，诱导用户安装。
* **勒索软件 (Ransomware)**：加密用户数据并索要赎金。

#### 常见攻击手段

* **垃圾邮件 (Spam)**：通过僵尸网络大规模群发。
* **网络钓鱼 (Phishing)**：
  * **常规钓鱼**：伪造银行或知名机构邮件获取凭证。
  * **鱼叉式钓鱼 (Spear Phishing)**：针对特定个人或公司的社交工程攻击。
* **SQL 注入**：针对服务器数据库的攻击。
* **拒绝服务攻击 (DDoS)**：利用大规模流量压垮目标服务器。
* **中间人攻击**：拦截并修改传输中的信息（HTTPS可防范此类攻击）。

#### 个人防御指南

非常重要 (必做)

* **强密码管理**：不要在多个重要站点使用相同密码；推荐使用密码管理器。
* **多因素认证 (2FA)**：即使密码泄露，没有手机令牌或硬件 Key 也无法登录。
* **保持更新**：及时更新浏览器和操作系统。
* **定期备份**：防止硬件故障或勒索软件攻击。

谨慎行事 (进阶)

* **禁用第三方 Cookie**：减少跨站跟踪。
* **使用拦截工具**：如 uBlock Origin（屏蔽广告和恶意脚本）。
* **保持警惕**：不打开陌生附件，不连接无加密的公共 Wi-Fi 处理敏感信息。


## 互联网上的数据

### 搜索

* **核心原理**：搜索引擎并非实时搜索，而是通过**爬虫 (Crawler)** 预先抓取网页，构建**索引 (Index)** 缓存。查询时通过高效算法（如 **PageRank**）从数据库中筛选最相关的 URL。
* **经济模型**：以**广告**为核心。广告位通过实时拍卖出售，定价标准包括展示次数、点击率和转换率。
* **潜在风险**：
  * **商业偏见**：靠广告支撑可能使搜索结果向出价者倾斜。
  * **社会偏见**：算法可能根据种族、性别特征进行定向投放，引发歧视。
* **替代方案**：如 **DuckDuckGo**，承诺不记录历史，提供非个性化结果。

## 精准广告

广告定位越精准，价值越高，这驱动了复杂的跟踪技术：

1. **Cookie**：服务器在浏览器存储的小文本块，可用于跨站识别。
2. **网络信标 (Web Beacons)**：隐藏的 **1x1 透明像素**图，用于探测用户是否访问了特定页面。
3. **JavaScript 监控**：记录鼠标轨迹、点击热点及表单输入。
4. **浏览器指纹 (Fingerprinting)**：利用操作系统、版本、字体、分辨率等特征组合，即使禁用 Cookie 也能唯一标识用户。
5. **地理位置跟踪**：手机 GPS、Wi-Fi 扫描和基站定位，形成高精度的物理轨迹。

## 社交网络与元数据

* **“免费”的代价**：如果你不为产品付费，你就是产品。社交网络将用户自愿分享的信息（个人偏好、社交图谱、位置）变现。
* **元数据的威力**：
  * **不仅是内容**：通话的时间、长度、频率（元数据）往往比通话内容更能揭示个人秘密（如拨打自杀热线或举报电话）。
  * **人脸识别与标记**：即使不使用社交网络，也可能被朋友标记，导致“被动”数据化。

## 数据挖掘：再识别与“大数据”

* **公共档案透明化**：原本需要物理访问的档案（房产、选民登记、捐款记录）现在被 **Zillow**、**FEC** 等网站聚合，匿名性消失。
* **再识别 (Re-identification)**：
  * **案例**：Latanya Sweeney 通过生日、性别和邮编三个特征，成功从匿名体检记录中锁定了马萨诸塞州州长的医疗隐私。
  * **结论**：真正的数据匿名化极难实现，多源数据整合能轻易还原个体身份。

## 云计算

* **模型转变**：程序和数据从本地电脑迁移至互联网“云端”（如 Gmail, Google Docs, Office 365）。
* **优势**：跨设备同步、实时协作、无需手动升级、数据备份。
* **风险与隐患**：
  * **主权与管辖权**：你的数据保存在哪国服务器，就受哪国法律管制（如《爱国者法案》）。
  * **法律透明度**：服务商收到政府传票（如“国家安全函”）时，可能被禁止告知用户。
  * **所有权边界**：工作账号的数据所有权属于雇主；个人服务商则可能根据其意愿决定是否抗拒不合理的数据索取。

## 保护个人隐私

数据是现代生活的“副产品”，它极大提升了生活效率（如精准导航、个性化推荐），但也让个人在政府和巨型公司面前变得近乎透明。**数字时代的生存法则是：在享受便利的同时，始终保持警惕，并意识到每一比特的数据都可能被永久保存。**

* **隐私现状：** 数字技术在带来便利的同时，也使无处不在的监视成为可能。计算能力的提升让个人信息的捕获、聚合与分析成本变得极低。
* **隐私定义：** 不仅仅是“隐藏秘密”，而是**权力和能力**去掌控个人生活的方方面面，防止商业利益体或政府机构在未经同意的情况下获取数据。
* **安全的多重含义：** * **国家/公司：** 保护资产免受攻击。
* **个人：** 隐私与安全密不可分，信息泄露直接威胁财务与人身安全。

| 级别 | 建议措施 |
| --- | --- |
| **非常重要** | 强且唯一的密码（或使用密码管理器）、开启**双因子身份验证 (2FA)**、定期备份、不点未知附件。 |
| **谨慎行事** | 禁用第三方 Cookie、安装 **uBlock Origin/Privacy Badger** 拦截跟踪器、在关键时刻使用隐身模式。 |
| **多疑者建议** | 使用 **NoScript** 禁用脚本、使用 **VPN** 或 **Tor** 浏览器、定期清理所有 Cookie、对设备进行硬件级加密。 |

## 密码学

密码学（Cryptography）是“秘密书写”的艺术，是抵御隐私攻击的最强手段，但常因人为错误失效。

### 基础概念与历史

* **古典密码：** 如凯撒密码（位移加密）和玛丽女王的复杂方案。
* **基本模型：** Alice与Bob 通信，对手 Eve 试图窃听。
* **密钥（Key）：** 加解密的核心。现代加密依靠复杂的数学算法和巨大的数字密钥。
* **攻击手段：** 频率分析（针对简单替换密码）、蛮力攻击（尝试所有可能密钥）、字典攻击。
* **原则：** **拒绝“隐匿式安全”**：**安全的系统必须假设攻击者完全了解算法**，安全性应仅依赖于密钥的保密。

### 密钥加密（对称加密）

* **定义：** 加密和解密使用**同一个密钥**。
* **主流算法：**
  * **DES** 旧标准，56位密钥，现已易被暴力破解。
  * **AES（高级加密标准）** 现代标准，支持128/192/256位密钥，目前无法通过蛮力攻击破解。
* 优点：非常快（AES 特别适合大流量）
* **局限性：** 存在
  * **密钥分发**问题（如何安全地把密钥交给对方）
  * **密钥扩散**问题（联系人多时管理困难）。

#### 13.1.3 公钥加密（非对称加密）

* **机制：** 每个人拥有一对密钥：**公钥**（公开给所有人）和**私钥**（严格保密）。
  * 用公钥加密的内容只能用对应的私钥解密
  * 比较慢，数学运算重（大整数/椭圆曲线），不适合直接加密大量数据
* **混合使用：** 公钥加密运算慢，实际应用中通常先用公钥加密协商出一个**临时密钥**，再用AES进行大量数据传输（如 **HTTPS**）
  * Step A：身份确认（关键）：
  * 服务器给你一个 证书（里面有服务器公钥 + 身份信息），证书由 CA 用 CA 的私钥做了数字签名。
    * 浏览器用内置的 CA 公钥验证签名 → 确认“这个公钥真是这个网站的”，避免中间人冒充。
  * Step B：协商出一个临时对称密钥（会话密钥）
    * 用非对称/密钥交换机制，把“这次会话用的 AES 密钥”安全谈出来（只谈一次或很少几次）。
  * Step C：正式传数据
    * 后续所有大量数据都用 AES（对称） 加密传输：快、效率高。
  * * **数字签名：** Alice 用私钥加密，别人用其公钥解密，证明消息确由Alice 发出且未被篡改。
* 底层原理
  * **RSA 算法：** 基于大整数分解的困难性。
  * **消息摘要（散列函数）：** 如 MD5、SHA-2、SHA-3。为文档生成唯一的“指纹”，用于检测篡改。

### 匿名技术与工具

#### 核心匿名工具

在线身份暴露

* **IP 地址：** 泄露地理位置。
* **浏览器指纹：** 通过字体、插件、用户代理等组合信息唯一识别用户，甚至禁用 Cookie 也会使特征更独特。

核心匿名工具

* **Tor（洋葱路由器）：**
  * **原理：** 流量通过三个随机中继节点，每层节点只知道上一级和下一级，剥离一层加密（像剥洋葱）。
  * **效果：** 隐藏真实 IP，突破地理限制，但速度较慢。
* **TAILS 系统：** 一种完全运行在内存中的操作系统，关机后不留任何痕迹，默认集成了所有加密工具。

### 比特币（加密货币）

* **特性：** 去中心化、基于区块链技术。
* **匿名性：** “冒名性”而非绝对匿名。所有交易公开在账本上，但地址与真实身份的关联需靠用户自行保护。
* **用途：** 既可用于合法交易，也因其匿名性被用于非法活动（如“丝绸之路”）

### 社会问题

* **密码学的双刃剑：** 它保护普通人的隐私，也保护犯罪分子。
* **后门争议：**
  * **政府观点：** 为了国家安全需要访问权限。
  * **技术界观点：** **“门垫下的钥匙”**不存在只给好人用的后门。一旦开了后门，系统就会变得脆弱，所有人（包括坏人）都能利用这个弱点。
* **最薄弱的环节：** 始终是**人**。复杂的密码规则、钓鱼邮件、社会工程学（4B：贿赂、勒索、盗窃、野蛮）是技术手段无法完全解决的。
